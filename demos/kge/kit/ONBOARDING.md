# Installation playbook

Start with [INSTALL.md](INSTALL.md) to install or upgrade the system. The kit’s installation playbook at `guides/operator.md` covers the operator’s work and is the only playbook shipped with the kit. Keep `scripts/playbook.py` beside `scripts/kge` to run it with `kge playbook operator`; read the complete guide first.

For work on the pages, open Context in the portal and choose Docs. The signed-in person sees the guides for their responsibilities and access, including connecting apps and AI agents. Dev team playbooks are maintained in the development repository and are not included in this kit.
