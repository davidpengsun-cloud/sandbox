# KGE release kit 0.14.29

These are the files of the release `kge-kit-v0.14.29`, with the prebuilt images, built from the same code as this repository's `demos/kge`. Use them to run KGE without building anything.

Both images are built on Red Hat's signed UBI 9 minimal bases, at their current digests: Python 3.12 for KGE, Node.js 22 for the portal. Neither runtime image carries npm, nodemon, the package installer or the pip wheel. The release's Trivy scan found no fixable HIGH or CRITICAL finding in either image; each remaining finding is listed in `images/scan-exceptions.json`, with its reason and expiry date.

GitHub refuses any file over 100 MB in a branch, so the two app images are split into parts under 50 MB. Join them before loading. Every other release file is as the release published it, and `SHA256SUMS` is the release's own. `README.md`, `join.cmd` and `.gitignore` are added here.

## 1. Join the images

On Windows, run `join.cmd` from this folder: in Command Prompt (`join.cmd`) or PowerShell (`.\join.cmd`), or by double-clicking it. It writes `images\kge-0.14.29.tar` and `images\kge-portal-0.14.29.tar` and prints their SHA-256. Compare those with the two lines for them in `SHA256SUMS`.

On Linux or macOS, or in Git Bash:

```
cat images/kge-0.14.29.tar.part-* > images/kge-0.14.29.tar
cat images/kge-portal-0.14.29.tar.part-* > images/kge-portal-0.14.29.tar
sha256sum -c SHA256SUMS
```

## 2. Load them

```
docker load -i images/kge-0.14.29.tar
docker load -i images/kge-portal-0.14.29.tar
docker load -i images/fake-gcs-server-1.56.1.tar
```

They load as `kge:0.14.29` and `kge-portal:0.14.29`, plus the Cloud Storage emulator that the Compose install runs. With Docker's containerd image store, each `.digest` file holds the image id that `docker image inspect --format '{{.Id}}'` shows once the image is loaded, as `docs/INSTALL.md` describes.

| `SHA256SUMS` | The release's checksums, for the joined images and every other file |
| `join.cmd` | Joins the image parts on Windows |
