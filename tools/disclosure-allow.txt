# Disclosure guard allowlist — tools/check_disclosure.py
#
# One exemption per line, four pipe-separated fields:
#
#   path | line | rule | reason
#
# The rule field may be left empty to exempt every rule on that line. The
# reason is mandatory: an entry that does not say why the line is not a
# disclosure is an unexamined leak with a note attached.
#
# Line numbers move when a document is edited. An exemption that no longer
# matches is silently inert, so re-run the guard after any edit to a file
# named here.
#
# Example:
